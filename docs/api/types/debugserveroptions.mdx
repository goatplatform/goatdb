# DebugServerOptions

Debug-server options extend the normal server options with SPA build settings,
live-reload hooks, custom `esbuildPlugins`, optional `openBrowser` control,
the pre-listen `setup(server)` hook, and the post-listen
`onReady({ server, url, stop })` hook. `url` is the chosen server origin,
`stop()` is idempotent, `startDebugServer()` resolves after clean shutdown and
rejects on startup failure or terminal watcher failure, and only one active
debug server instance is supported at a time.
